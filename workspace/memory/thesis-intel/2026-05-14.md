# Thesis Intel — 2026-05-14

## TL;DR (3 bullets)
- Document AI sigue consolidándose en “plataformas” (no solo OCR), con presión real de migración/versionado y foco en extracción estructurada.
- La ola “agentic workflows inside business tools” baja a SMB, es un blueprint directo para copilotos de brokers/agencias con conectores + aprobaciones.
- Señales locales (Uruguay) de mejor data de siniestralidad laboral abren espacio para productos/analítica de prevención y pricing.

## Hallazgos (6–10)
1) Azure Document Intelligence v4.0 (GA) y deadlines de soporte
- Por qué importa para la tesis: refuerza que el stack de IDP/OCR se está moviendo a APIs versionadas con ventanas de soporte largas, ideal para productos B2B con compliance.
- Links: https://learn.microsoft.com/en-us/azure/ai-services/document-intelligence/overview
- Idea accionable para Brokia: diseñar el pipeline de “ingesta documental” con adaptadores por proveedor (Azure/otros) + contrato de salida común (JSON esquema), para permitir swap por costo/latencia/región.

2) “Claude for Small Business” (conectores + workflows listos)
- Por qué importa para la tesis: valida que el camino ganador no es “chat”, sino automatización dentro de herramientas (contabilidad, pagos, CRM, firmas) con aprobación humana.
- Links: https://www.anthropic.com/news/claude-for-small-business
- Idea accionable para Brokia: prototipo de “broker workflow pack” (CRM + Docs + Email + Pagos) con 5 flujos: renovación, endoso, cobranza, siniestro, seguimiento.

3) BitLocker “YellowKey” (riesgo de supuestos de cifrado en endpoint)
- Por qué importa para la tesis: sistemas con PII (pólizas, siniestros, audios) necesitan threat model realista, especialmente si hay laptops/dispositivos con acceso físico.
- Links: https://www.tomshardware.com/tech-industry/cyber-security/microsoft-bitlocker-protected-drives-can-now-be-opened-with-just-some-files-on-a-usb-stick-yellowkey-zero-day-exploit-demonstrates-an-apparent-backdoor
- Idea accionable para Brokia: checklist de hardening operativo (rotación de recovery keys, políticas de almacenamiento de docs/exports, cifrado app-level para adjuntos sensibles).

4) Observatorio de Accidentes de Trabajo y Enfermedades Profesionales (MTSS + BSE)
- Por qué importa para la tesis: mejor granularidad y timeliness en siniestralidad puede impulsar pricing dinámico, prevención, y productos paramétricos/servicios de seguridad.
- Links: https://www.gub.uy/presidencia/comunicacion/noticias/accidentes-laborales-banco-seguros-observatorio-mtss
- Idea accionable para Brokia: módulo de “prevención” con alertas por industria/actividad y recomendaciones accionables (con auditoría) para reducir siniestralidad.

5) Capacitación AcelerIA para sector turismo (Mintur + UTEC)
- Por qué importa para la tesis: evidencia adopción institucional de IA aplicada en servicios, útil para validar go-to-market y alianzas locales.
- Links: https://www.gub.uy/presidencia/comunicacion/noticias/turismo-trabajadores-inteligencia-artificial-menoni-mayo-2026
- Idea accionable para Brokia: explorar partnerships con programas de formación para “AI literacy” en corredores/agencias (manual operativo + prompts + compliance).

6) “Arena AI Model ELO History” (drift/variabilidad de modelos)
- Por qué importa para la tesis: si los modelos cambian, los productos deben tener evaluación continua, rutas de fallback, y contratos de calidad.
- Links: https://mayerwin.github.io/AI-Arena-History/
- Idea accionable para Brokia: armar harness de regresión con “golden cases” (pólizas, siniestros, intents) + métricas (exactitud extracción, alucinación, latencia, costo) y alertas.

## Ideas accionables para Brokia (3–5)
- Diseñar arquitectura “connector-first” + aprobación humana, alineada con el patrón SMB que están empujando los labs.
- Implementar dedupe + auditoría: cada salida del LLM con trazabilidad (fuente, fecha, versión de modelo, prompt hash).
- En compliance: definir baseline de retención/PII redaction para docs y audio (logs + export control).
- En producto: módulo de prevención/seguridad laboral (si el Observatorio entrega data útil), como wedge para líneas comerciales.
