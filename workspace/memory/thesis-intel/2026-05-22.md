# Thesis Intel — 2026-05-22

## TL;DR
- Insurers are moving from “AI pilots” to production automation (ops + claims), but governance and human override are becoming the competitive differentiator.
- Claims automation and fraud risk are increasingly coupled: faster decisions raise bad-faith and adversarial manipulation risks, pushing demand for audit logs and explanation layers.
- A near-term Brokia wedge: broker-facing copilots that generate compliant, auditable artifacts (email, quote comparatives, renewal rationale) with PII-redaction + traceable sources.

## Ideas accionables para Brokia
- Build an auditable “Renewal/Quote Rationale Generator” that outputs: comparison table, key deltas, exclusions, and a compliance appendix with citations.
- Ship PII redaction + data residency controls as a first-class feature (toggle per client), with immutable audit logs.
- Create a simple policy for “when to force human review” (risk scoring) and expose it as configuration, not code.
- Prototype an “evidence packet” export (PDF/zip) for disputes, tying every output back to extracted sources.
