# Thesis Intel — 2026-05-26
## TL;DR
- Prioritize document-ingestion quality: layout + tables + eval benchmarks are still the moat.
- Voice agents: latency + safety (anti-spoofing) are becoming table stakes for customer-facing flows.
- Compliance-ready RAG: audit logs + PII redaction remain the fastest path to enterprise adoption.

## Hallazgos
1) Document AI evaluation remains under-specified in many products
   - Why it matters for the thesis: Without repeatable eval (tables/forms), accuracy claims are fragile.
   - Links: https://arxiv.org/search/?query=document+information+extraction+benchmark&searchtype=all
   - Actionable idea for Brokia: Build a small “policy packet” benchmark set (10–20 real-ish docs) and track extraction F1 over time.

2) Table extraction is still a failure mode in real workflows
   - Why it matters: Insurance documents are table-heavy (coverages, limits, exclusions).
   - Links: https://arxiv.org/search/?query=table+extraction+deep+learning&searchtype=all
   - Actionable idea: Add a table-first pipeline (detect → structure → validate totals) before LLM summarization.

3) Secure RAG patterns: redaction + least-privilege retrieval
   - Why it matters: PII and regulated data will block adoption if not designed in.
   - Links: https://arxiv.org/search/?query=pii+redaction+nlp&searchtype=all
   - Actionable idea: Implement pre-index redaction and post-retrieval masking with an audit trail.

4) Voice agent reliability depends on end-to-end latency budgets
   - Why it matters: Broker/customer calls tolerate little delay.
   - Links: https://arxiv.org/search/?query=real-time+speech-to-speech+latency&searchtype=all
   - Actionable idea: Define SLOs (p95 round-trip) and test on mobile networks.

5) Anti-spoofing and deepfake detection is becoming mandatory for voice flows
   - Why it matters: Fraud vectors increase with voice cloning.
   - Links: https://arxiv.org/search/?query=voice+spoofing+detection&searchtype=all
   - Actionable idea: Add liveness checks or risk scoring before high-impact actions (policy changes, payouts).

6) Broker copilot trend: summarization + next-best-action from docs + CRM context
   - Why it matters: This is the direct product wedge for Brokia.
   - Links: https://www.cbinsights.com/research/ (search insurtech AI)
   - Actionable idea: Prototype “renewal brief” generator that cites exact policy clauses.

## Ideas accionables para Brokia
- Ship an evaluation harness for document extraction (tables + forms) as a first-class feature.
- Add compliance mode: redaction, data retention, audit logs.
- Voice: enforce latency SLO + anti-spoofing gate for sensitive actions.
