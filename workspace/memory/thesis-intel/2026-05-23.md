# Thesis Intel — 2026-05-23

## TL;DR
- Enterprise AI security tooling is moving “up the stack” into productized features (threat models, vulnerability disclosure, access controls).
- Workflow-embedded AI (Office, design tools) continues to compress switching costs and drives adoption via distribution.
- Infra economics still dominate: record data center demand keeps cost, capacity, and vendor lock-in as core constraints.

## Ideas accionables para Brokia
- “Evidence packet” export: for every automated decision/artifact, bundle inputs, citations, extracted fields, reviewer actions, and timestamps.
- Governance-first onboarding: a 30-minute checklist (data retention, access control, redaction, evaluation) that becomes a signed client artifact.
- Cost telemetry by default: per-workflow cost, cache hit rate, and failure taxonomy to keep margins predictable.
- Structured spec + validation: do not allow free-form outputs to leave the system without schema validation and compliance checks.
