# Thesis Intel — 2026-05-04
## TL;DR
- Provenance/identity is becoming a first-class product surface (badges, eligibility rules), expect it to reach regulated docs/voice workflows.
- Defense and public-sector procurement continues to pull secure AI stacks (audit logs, evaluation, governance).
- Energy/geopolitics volatility is a reminder: build cost controls and resiliency assumptions for “shock weeks”.

## Hallazgos
1) Content provenance hardening is moving mainstream (Spotify “Verified”, Oscars AI rules)
- Why it matters for the thesis: Broker/claims communications and document workflows will need “human verified”/traceability primitives.
- Links:
  - https://www.bbc.com/news/articles/c5yerr4m1yno
  - https://www.bbc.com/news/articles/cx21dl3v7d3o
- Actionable idea for Brokia: Add an audit-ready “provenance ledger” for every inbound doc/audio (who/when/how processed, model versions, hashes).

2) “AI-first” procurement in defense keeps expanding
- Why it matters for the thesis: Sets security + compliance expectations that later propagate to regulated private sectors (finance/insurance).
- Links:
  - https://www.bbc.com/news/articles/cy02gjq2987o
- Actionable idea for Brokia: Build a minimal “evidence pack” export (logs, prompts, redaction proof, eval results) for enterprise compliance reviews.

3) Edge compute packaging keeps getting weird (lamppost micro data centers)
- Why it matters for the thesis: If edge inference grows, on-device/near-device document capture and fraud checks become viable.
- Links:
  - https://www.bbc.com/news/articles/c98r4e594p7o
- Actionable idea for Brokia: Prototype offline-first mobile capture + deferred upload with on-device redaction for low-connectivity agents.

4) Model behavior drift and subtle regressions remain a product risk
- Why it matters for the thesis: Broker/claims automation must be regression-tested like software, not treated as “static”.
- Links:
  - https://www.bbc.com/news/articles/c5y9wen5z8ro
- Actionable idea for Brokia: Maintain a small gold set of real docs/voice snippets and run daily eval (extraction accuracy, PII leaks, hallucination rate).

5) Energy/geopolitics shocks flow into operational cost and customer stress
- Why it matters for the thesis: Shock periods change fraud patterns and claim volumes; cost control matters when inference demand spikes.
- Links:
  - https://www.ft.com/content/483a0aa0-f1c8-4960-be68-c6ea3e9ea3d5
- Actionable idea for Brokia: Add “cost guardrails” (rate limits, batching, caching) and a playbook for high-volume days.

6) Supply-chain resilience is being encoded into agreements
- Why it matters for the thesis: Compliance, auditability, and data-sharing norms can tighten quickly across borders.
- Links:
  - https://www.ft.com/content/d9e48c9c-4c6f-4ac9-8fe1-a50272697d3e
- Actionable idea for Brokia: Make data residency + retention configurable per client, with a clear audit trail and deletion guarantees.

## Ideas accionables para Brokia
- Ship an “evidence pack” export: audit logs + model versions + eval metrics per case.
- Add provenance/identity primitives (human verified, doc hash chain, signed approvals) across doc + voice.
- Stand up daily regression eval on a gold dataset (docs + voice), with alerting on drift.
- Implement cost guardrails: caching, batching, tiered model routing, and a high-volume playbook.
