# Thesis Intel — 2026-05-15

## TL;DR
- Evidence is mounting that “agent harness” design choices (inline vs file-based tool outputs) can dominate retrieval method choice, with grep-style retrieval often beating vector RAG on long-context memory tasks.
- LLM security risk is broader than prompt text, a new backdoor class exploits positional encodings (length/position as triggers) enabling stealthy misbehavior and potential secret leakage.
- Multilingual embeddings are pushing toward “efficient-by-design” releases (models + data + code), a useful baseline for LATAM language coverage and cost-controlled semantic search.

## Hallazgos
1) Is Grep All You Need? How Agent Harnesses Reshape Agentic Search
- Por qué importa: If grep-like lexical retrieval outperforms vector retrieval in realistic agent loops, Brokia’s doc QA may benefit from hybrid (lexical-first) retrieval and better tool I/O packaging before investing heavily in embeddings.
- Links:
  - https://arxiv.org/abs/2605.15184
- Idea accionable (Brokia): Run an A/B on policy PDF QA: (A) BM25/grep-first + small reranker, (B) vector-only, keeping the same agent harness. Measure answer faithfulness and “time-to-correct”.

2) Exploiting Positional Encoding as a Backdoor Attack Surface in LLMs
- Por qué importa: Threat model for “safe assistants” must include non-text triggers (context length/position), relevant for voice-to-text chats and long-running broker copilots.
- Links:
  - https://arxiv.org/abs/2605.15172
- Idea accionable (Brokia): Add a “conversation length guard”: periodically summarize + truncate and re-initialize tool permissions, reducing exposure to length-based trigger regions.

3) OpenDeepThink: Parallel Reasoning via Bradley–Terry Aggregation
- Por qué importa: Test-time compute scaling can improve reasoning by breadth, but selection needs robust aggregation. Useful for claims triage or underwriting explanations where verifiable checks exist.
- Links:
  - https://arxiv.org/abs/2605.15177
- Idea accionable (Brokia): For structured outputs (coverage decision, required docs), generate 6 candidates, do pairwise votes, then choose top. Constrain judging prompts to verifiable criteria.

4) Inclusive and Efficient Embeddings for a Multilingual World (ML-Embed, ICML 2026)
- Por qué importa: Strong multilingual embedding baselines reduce vendor lock-in and improve retrieval for Spanish + regional language variance, with explicit attention to efficiency.
- Links:
  - https://arxiv.org/abs/2605.15081
- Idea accionable (Brokia): Benchmark embeddings on Spanish insurance docs: compare recall@k for key clauses (deductible, exclusions, waiting periods) vs current setup.

6) (Infra/cost) Retrieval packaging beats retrieval math
- Por qué importa: The same retrieval method can perform very differently depending on whether tool results are inline vs file-based, and how much irrelevant context is mixed in.
- Links:
  - https://arxiv.org/abs/2605.15184
- Idea accionable (Brokia): Standardize “evidence pack” format (doc_id, page, quote, hash) and require the model to cite pack IDs, not free-form URLs.

## Ideas accionables para Brokia
- Build a hybrid retrieval prototype: lexical-first (BM25/grep) + optional vector fallback, and measure hallucination rate on policy PDFs.
- Add “length/position defense” in assistants: periodic reset, permission re-ask, and tool-call allowlist after N turns.
- Use breadth+aggregation for any decision with a deterministic checker (e.g., required-doc checklist).
